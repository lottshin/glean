# Glean 拾穗

在 Obsidian 里精听视频、阅读英文笔记，并把遇到的词连同原句沉淀成自己的 Markdown 生词库。

你来是为了内容本身；语言是顺路捡起来的东西。

> 当前为 `0.0.1` 开发预览版，最低 Obsidian `1.6.6`。浏览器采集只在桌面端进行；同步后的材料可在桌面、iPad 和手机学习。尚未提交社区插件市场。

Glean 本身不抓网页。第一次启用后会提示两个浏览器扩展：

- **Obsidian Web Clipper**（[官方](https://obsidian.md/clipper)）：把网页存进 vault，再用 Glean 阅读。
- **Glean Capture**：从 YouTube 同步字幕，或从 B 站同步英文字幕和纯音频。尚未上架商店时，用灰度 zip 在 Chrome / Edge 加载已解压的扩展。

详情在 **设置 → Glean** 顶部；侧边栏麦穗菜单也有「浏览器扩展…」。

## 核心工作流

### 精听

1. 把本地视频或音频放进 vault，并配一份同目录、同名的 `.srt` / `.vtt` 字幕。
2. 右键媒体选择 **Glean: 精听**，或点击侧边栏 Glean 图标后在菜单中选择 **精听**。
3. 点击字幕句子重听，点击句中单词查看离线释义。
4. 点击 **加入生词**，Glean 会创建普通 Markdown 词卡，保存原句、媒体路径和时间戳。
5. 从词卡点击时间戳，可重新打开 Glean 并跳回原句。

精听快捷键：

- `Space`：播放 / 暂停
- `R`：重听当前句
- `[` / `]`：上一句 / 下一句
- `-` / `=`：降低 / 提高倍速
- `D`：精听 / 听写切换
- `H`：听写模式显示 / 隐藏原句

### YouTube 采集与跨端学习

桌面浏览器扩展负责从当前 YouTube 页面读取已有字幕，桌面 Obsidian 的 Glean 接收端把字幕与会话笔记写入 `Glean/YouTube/`。这些都是普通 vault 文件，可经 Obsidian Sync 到 iPad 和手机。

1. 运行 `npm run extension:build`，在 Chrome / Edge 的扩展管理页加载 `extension/dist/`。
2. 在 **设置 → Glean → YouTube 采集接收端** 确认端口并复制 token。
3. 把端口和 token 填入扩展，打开带字幕的 YouTube 视频，选择字幕语言后同步。
4. 在 Obsidian 打开生成的会话笔记，运行 **Glean: 精听当前 YouTube 笔记**。

扩展只读取页面已有字幕，不下载音视频。采集需要桌面 Obsidian 正在运行；iPad 和手机无需安装浏览器扩展。移动端播放仍依赖 YouTube 网络和嵌入能力，若环境报 Error 153，字幕阅读、查词和生词库仍可使用。

### 阅读

打开普通 Markdown 英文笔记，通过侧边栏 Glean 图标菜单、标题栏麦穗图标、文件右键菜单或命令 **Glean: 阅读当前笔记** 进入显式阅读模式。

- 正文保持连续，英文词可点击查义。
- `new` / `learning` 状态以轻量底线提示，`known` / `ignored` 不染色。
- 顶部状态栏显示文本侧的「常用 3000 词覆盖率」和本文实际入库的生词数，不猜测用户认识多少词。
- 设置中的「阅读词汇提示」可调节较难词的虚线提示密度；它只改变界面，不会自动建卡。
- 从阅读弹层入库时，词卡保存当前句和来源笔记链接。
- 已入库词可在弹层中直接切换为生词、学习中、已掌握或忽略。

阅读模式只修改渲染出来的界面，不改原始文章。

### 生词库

点击侧边栏麦穗，在菜单中选择 **生词库**，或运行命令 **Glean: 打开生词库**。生词库停靠在右侧边栏，不需要再展开 `Glean/Words` 的字母目录。

- 搜索 lemma 或记录过的词形。
- 按生词、学习中、已掌握、忽略筛选。
- 在列表中直接修改状态、移出生词或打开 Markdown 词卡。
- 点击来源可打开原笔记或媒体。
- 一次只渲染 100 条，词卡较多时用「再显示」逐批加载。

### 整句解析

整句解析是一段会话，不是一次浮层。它停靠在正文右侧，正文让出宽度而不是被遮住，因此可以边读边开着。

- **打开**：选中一句或一段，点状态栏的 **解析选区**，或用命令 **Glean: 解析选中句子或段落**。划选本身不会弹出任何东西。
- **换句**：面板开着时，再划一句就直接换内容，不用再点一次按钮。点词、滚动正文、滚动面板都不会关掉它。
- **关闭**：Esc、面板右上角的 ×、再点一次状态栏按钮（此时显示 **收起解析**），或退出 Glean 阅读。

面板分两部分：

- **逐词释义**：离线进行。按出现顺序列出实词，虚词和停用词不占位置，同一 lemma 的不同词形合并成一条。每条右侧的「加入」直接建卡，语境记为当前选区。
- **翻译**：默认关闭。开启后也只在你点「翻译这段」时才发请求；换到新的一句会清掉上一句的译文，不会自动重新翻译。

拖选文字不会触发单词弹层，可以放心划句子。

### 在线翻译（可选）

整句翻译需要联网，因此默认关闭，开关在 Glean 设置的「在线整句翻译」。

- 支持 **OpenAI 兼容** 接口（可指向任意兼容服务）和 **DeepL**。OpenAI 兼容可从当前接口拉取 `/models` 列表，中转站未实现时仍可手动填写模型名。
- 只有你点击「翻译这段」时才发出请求，没有后台预翻译，也不会翻译整篇文章。
- 单次选区上限 4000 字，超出会提示分段。
- API key 以明文存放在插件数据里，共享 vault 请勿填写。
- 关闭开关时，整句解析只用本地词典，选区内容不会离开这台设备。

## 生词数据

生词默认存放在 `Glean/Words/<首字母>/<lemma>.md`。一词一篇 Markdown，`lemma` 是主键；听力和阅读遇到的语境会追加到同一张卡。

已入库的词可以从查词弹层、词卡顶部按钮、标题栏图标、文件右键菜单或命令面板移出。文件进入 Obsidian 配置的废纸篓，不会直接永久删除。

字段格式、目录迁移、性能与 Anki 边界见 [生词库文档](docs/lexicon.md)。

## 离线词典

Glean 使用 ECDICT 生成的排序 TSV，不联网查词。桌面端按需读取磁盘，移动端通过 vault adapter 载入词典。词典文件为：

```text
glean-dict-v1.tsv
glean-inflect-v1.tsv
```

正式构建会把压缩词典随插件一起发布。首次启用时，Glean 会校验并解压到 vault 配置目录的 `glean/dict/` 下，整个过程不联网；安装后也可完全离线查词。也可以在 Glean 设置里指定其他目录或重新安装。开发者可按 [词典文档](docs/dictionary.md) 从 ECDICT 构建。

### 安装词典

正常安装插件不需要单独处理词典。若首次自动安装失败，可以在 **设置 → Glean → 离线词典目录** 点击 **安装内置词典** 重试。

需要手动维护词典时，将两个 TSV 文件放到：

```text
<vault>/.obsidian/glean/dict/
```

重新加载词典后，设置页应显示“已加载 Glean 离线词典”。如果使用其他位置，在设置中填写绝对路径或相对 vault 根目录的路径。词典损坏或配置目录不完整时，Glean 会显示具体目录，但仍允许把未收录词以空释义入库。

## 安装

### 灰度安装包

需要 Obsidian 1.6.6 或更高。解压 `glean-0.0.1.zip`，把里面的三个文件放到：

```text
<vault>/.obsidian/plugins/glean/
```

目录中应正好是 `main.js`、`manifest.json`、`styles.css`。然后打开 **设置 → 第三方插件**，关闭安全模式并启用 **Glean**。首次启用时会把离线词典解压到 `.obsidian/glean/dict/`，不联网；设置页应显示「已加载 Glean 离线词典」。同时会提示安装官方 **Obsidian Web Clipper** 和 **Glean YouTube Capture**，说明在 **设置 → Glean** 顶部。

不要把 TypeScript 源码拷进插件目录。当前 `0.0.1` 仍是开发预览，未上社区市场。本地打包：

```bash
npm run build
mkdir -p dist/glean
cp main.js manifest.json styles.css dist/glean/
cd dist && zip -r glean-0.0.1.zip glean
```

### 源码安装

```bash
npm install
npm test
npm run build
```

把仓库放到或软链接到：

```text
<vault>/.obsidian/plugins/glean/
```

确保目录中存在 `manifest.json`、`main.js` 和 `styles.css`，然后在 Obsidian 的第三方插件设置中启用 Glean。

开发时运行：

```bash
npm run dev
```

配合 Obsidian Hot Reload 插件和仓库根目录的 `.hotreload` 标记，可在源码变化后自动重载。

## 验证

```bash
npm run build

```

## 当前边界

- YouTube 只采集页面已有字幕，不抓取无字幕视频，也不下载或缓存音视频；B 站尚未实现。
- YouTube 嵌入受视频作者设置和运行环境影响，可能出现 101 / 150 / 153 错误。
- 阅读模式目前作用于 Markdown 阅读视图；手动切回源码模式会自动退出 Glean 阅读。
- 阅读嵌入内容时，语境归属当前打开的来源笔记；交互链接和代码不会被改造成可查词单词。
- 逐词释义只覆盖离线词典收录的词，不做语法分析，也不解释固定搭配和习语。
- 在线翻译只做译文，不返回语法讲解；未配置服务商时该区域始终为空。
- 媒体改名后 Glean 会尝试恢复回跳；如果 vault 中有多个同名媒体，会提示手动打开，避免跳错文件。
- 不自研 SRS；未来 Anki 只作为可选导出和调度端，Markdown 仍是权威数据。
